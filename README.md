### Saving work permanently to GitHub

As you work through the tasks, and at the end of the session, remember to save your files from Codespaces (where they exist in your temporary workspace) to GitHub, using the command below in the lower terminal panel:

```
git_helper --commit
```


### Downloading your work for the assessed portfolio

In the terminal, in your repository folder, run the following command to build a zip of the work you completed in the workshop:

```
git_helper --zip
```

This commits your work and creates a zip file of your work. You will see it in the file panel.

Right click on the zip file to download a copy to your computer.
